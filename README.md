# Rubik's Cube Solver

An interactive Rubik's Cube solver that can solve cubes in as fast as 0.81 seconds! Check out the [itch.io page](https://matoe.itch.io/rubiks-cube-solver) to use in your browser, or download the source code here to compile. 
This project was made entirely using Java and uses the LibGDX graphics engine to render.
